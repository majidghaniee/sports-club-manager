# سامانه جامع مدیریت باشگاه ورزشی (Sports Club Manager)

اپلیکیشن کامل مدیریت باشگاه‌های ورزشی با رابط کاربری راست‌به‌چپ (RTL)، تقویم شمسی و پشتیبانی از پایگاه‌داده آفلاین محلی (SQLite / Drift).

## قابلیت‌های کلیدی
1. **مدیریت اعضا (Member Management)**
   - ثبت، ویرایش و حذف مشخصات کامل (نام، تلفن، کد ملی، تاریخ تولد شمسی، رشته ورزشی، نوع و انقضای عضویت، عکس)
   - جستجوی بلادرنگ و فیلتر براساس رشته ورزشی و وضعیت فعالیت
   - تولید بارکد اختصاصی QR برای هر عضو در صفحه پروفایل

2. **ثبت حضور و غیاب هوشمند (Attendance Tracking)**
   - اسکنر QR دوربین جهت ثبت سریع ورود اعضا
   - ثبت دستی ورود و خروج
   - تقویم شمسی برای مرور تاریخچه تردد روزهای گذشته

3. **مدیریت مالی و شهریه (Payment Management)**
   - ثبت شهریه، سرسید، مبالغ و شماره رسید
   - تفکیک وضعیت پرداخت و برجسته‌سازی معوقات (Overdue Alerts)

4. **مدیریت بیمه ورزشی (Insurance Management)**
   - پیگیری تاریخ اعتبار بیمه، شرکت ارائه‌دهنده و شماره بیمه‌نامه
   - هشدار خودکار بیمه‌های رو به انقضا (کمتر از ۳۰ روز) و منقضی‌شده

5. **داشبورد آماری (Dashboard)**
   - نمایش کارت‌های شاخص: تعداد کل اعضا، حاضرین امروز، شهریه‌های معوق و بیمه‌های نیازمند تمدید
   - منوی دسترسی سریع به عملیات پرکاربرد

6. **گزارش‌گیری و خروجی PDF (Reports)**
   - خروجی استاندارد A4 همراه با فونت فارسی (وزیرمتن)
   - امکان چاپ مستقیم یا اشتراک‌گذاری فایل گزارش در پیام‌رسان‌ها

7. **شخصی‌سازی و تنظیمات (Settings)**
   - تغییر نام و لوگوی باشگاه
   - حالت روز / شب / هماهنگ با سیستم
   - تنظیمات یادآورها

## معماری و پشته فنی
- **فریمورک:** Flutter (Dart 3+)
- **پایگاه‌داده محلی:** Drift + SQLite (کامل با DAO و استریم)
- **مدیریت وضعیت:** Flutter Riverpod 2
- **مسیریابی:** GoRouter (همراه با ShellRoute برای تب‌بار زیرین)
- **تقویم و تاریخ:** shamsi_date + intl
- **تولید و اسکن QR:** qr_flutter + mobile_scanner
- **تولید PDF:** pdf + printing
- **سیستم طراحی و رنگ:** مبتنی بر HSL الهام‌گرفته از OKLCH (تم سبز ورزشی و امبر)
